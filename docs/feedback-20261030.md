## 已确认的交互

用户明确选择：**所有主界面取消行内任务输入，统一用「＋」打开新增面板。** 悬浮栏点击「＋」后的快速输入是独立快捷入口，仍按原架构按需创建和释放。

| 入口 | 用途 | 新增规则 |
| --- | --- | --- |
| Agent 待确认 | 独立审核页，核对新增和修改申请 | 无常驻输入和页面新增按钮，批准／拒绝使用原核心规则 |
| 今天 | 集中执行今天和仍未完成的逾期任务 | 右上角「＋」默认今天，可修改 |
| 最近 7 天 | 按日期分组查看近期及逾期安排 | 右上角「＋」默认今天，分组「＋」默认该组日期 |
| 收集箱 | 查看尚未归入其他清单的任务 | 「＋」默认收集箱、无日期 |
| 所有任务 | 检索、筛选和整理任务全集 | 「＋」默认收集箱、无日期 |
| 自建清单／标签 | 按清单或标签查看任务 | 同一新增面板保留对应清单／标签上下文 |
| 日历 | 月、周、日、日程视图排期 | 保留现有日期格和日期范围创建交互，使用同一新增面板 |
| 已完成／回收站 | 查看已结束任务、恢复或销毁 | 不显示页面新增按钮 |

这些入口读取同一份任务，并不创建五份任务库。例如一条属于收集箱、日期是今天的任务，会同时出现在收集箱、今天、最近 7 天和所有任务。列表适合逐项处理和筛选，日历负责时间分布，两者保持互补。本轮不新增另一种“看板”布局。

Ctrl+N 与当前页面「＋」使用相同默认日期；“已过期”汇总组的「＋」默认今天。新增面板显示所属清单和日期；“明天开会”等中文日期优先于页面默认值，只有用户明确选择的日期才覆盖解析结果。主动清空日期后不再重新补回。保存失败保留表单内容和请求号。

## 导航就地整理

- 左下角固定为标准齿轮设置按钮，撤除独立的“编辑导航”按钮和弹窗。
- 左侧功能图标和侧栏入口长按约 500ms 进入整理；继续按住可直接拖动，普通短点击仍进入页面。
- 整理状态显示落点线、隐藏／恢复按钮；原先已隐藏入口在整理中显示为淡色，便于恢复。
- 点击「完成」一次保存布局；「取消」或 Esc 撤回未提交的整理。保存失败保留整理状态与错误提示。
- 顺序和隐藏沿用 Rust 的 `navigationUpdate`，包括 Agent 待确认。设置入口固定且不可隐藏。
- 既有任务拖入分类、清单归组、标签与清单的右键操作继续保留；不在正常导航状态增加持续动画或轮询。
