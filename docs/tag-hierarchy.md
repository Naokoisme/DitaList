# 标签与清单层级

日期：2026-11-02（Asia/Shanghai）。

拖放与子清单增量：2026-11-03（Asia/Shanghai）。

标签支持最多三层，主标签计第一层，第三层按需要建立。例如：

```text
学校
├─ 数据结构
│  ├─ 作业
│  └─ 论文
└─ 形势与政策
   ├─ 作业
   └─ 论文
```

## 显示与使用

- 侧栏默认显示主标签，点箭头逐层展开，缩进与连接线表示收纳关系。点击名称筛选任务；点击父标签同时查看全部下级任务，每项任务只计一次。
- 主标签和课程行右侧的「＋」可直接创建子标签；标签设置中也可以选择「所属标签」，路径预览展示保存后的层级。第三层标签不提供继续创建子标签的入口。
- 普通任务行只显示去重后的主标签。鼠标悬停显示完整路径；任务详情保留「学校 › 数据结构 › 作业」这样的完整路径。
- 任务详情中的「搜索或添加标签」可以按课程或类型查找，选择一次子标签即可。直接输入新名称可以添加独立的一级标签。
- 编辑标签可以更名或修改所属标签。核心统一移动整棵子树，并更新任务、导航和已保存的筛选条件。超过三层、循环或名称冲突会保留原数据并提示错误。
- 删除标签会移除它及全部下级与任务的关联，任务本身会保留。保存筛选中的旧条件保留，避免删除条件后扩大筛选范围。

## 拖动归类与排序

标签和清单都支持直接拖动。拖到目标中央、出现「移入」提示时松手，整个项目及其下级将归入目标；拖到上下边缘、出现排序线时松手，则调整同级位置。拖回对应区域的顶层落点可以移出父级，清单也可以拖回分组。松手前取消不会改变原来的归属。

清单支持三层，父清单仍可以直接保存任务。点击父清单汇总自身及全部下级任务，计数按任务去重。清单分组继续作为外层容器，层数从主清单开始计算。层级移动保留任务原来的清单关联；详情与新任务的清单选择器展示完整路径。

清单删除和归档保持只处理当前清单：其直属子清单提升一级并保留自己的下级，删除清单的直接任务转入收集箱。三层上限、自身／后代循环、归档目标和收集箱等限制由核心统一处理，界面提供禁止落入的反馈。

长按进入的「整理导航」继续用于导航排序和隐藏，普通拖动即可归类，无需先进入整理模式。

## 旧数据与接口

现有标签保持为一级标签。旧标签名称中包含 `/` 时，仍作为完整名称显示；层级只按明确的父子关系识别。备份、导入和重新打开保留层级。

任务只保存直接选择的标签。快照由 Rust 核心提供名称路径与子树成员索引，界面和 MCP 使用同一份索引。MCP 查询可以用完整标签键筛选父级及全部下级，标签管理仍由本地用户执行。共享合同见[三层标签接口](interfaces.md#三层标签)。

本轮检查覆盖核心持久化、备份、任务关联、失败原子性和界面交互。最终候选目录的 `verification.json` 记录该候选实际执行的桌面检查与产物核对，检查范围以记录为准。
