# DitaList Rust Preview · 2026-10-30

当前发布条目：[v0.0.0-rust-preview.20261030](https://github.com/Naokoisme/DitaList/releases/tag/v0.0.0-rust-preview.20261030)。产品版本仍为 `0.0.0`，源码以 Release 标签和包内 `build-info.json` 的完整提交号核对。

## 本版内容

- Windows 主线迁移到 Tauri＋Rust，保留现有任务、日历、清单、标签、筛选、习惯、专注和导入备份。
- 原生悬浮栏贴边收成白色细线，移入展开；完整主窗口采用水滴式流出，冷开、短时隐藏及最小化恢复共用展开路径。
- 主任务页面统一用「＋」新增，Agent 使用独立审核页；左侧导航长按原位拖动排序／隐藏，左下角为齿轮设置。
- MCP 默认关闭，通过标准 stdio 接入；内部自动发现本机地址并核对实例身份。创建／修改先审核、删除进回收站，重试复用业务请求号。
- 本地架构、设计、迁移、验证文档及历史证据一起归档。历史试用安装包不补发为新 Release。

## 下载和覆盖安装

| 文件 | 用途 |
| --- | --- |
| `DitaList-Rust-Preview-Setup.exe` | Windows x64 安装与同一 Rust Preview 的覆盖升级；缺少 WebView2 时联网补装 |
| `DitaList-Rust-Preview-Portable.zip` | 免安装运行，需已有 WebView2；解压后保留主程序与 MCP 在同一目录 |
| `DitaList-Documentation.zip` | 同一标签下的 README、项目文档、证据与现有组件截图 |
| `SHA256SUMS.txt` | Release 各附件的 SHA-256 校验清单 |
| `artifacts.json`、`build-info.json`、`release-verification.json` | 源码来源、包内文件与发布核对记录 |

覆盖安装前从托盘选择「退出」，再运行 Setup。数据仍在 `%APPDATA%\DitaListRustPreview\data`，安装器不删除该目录。原 Electron 版使用独立目录和数据；需要迁移时从设置显式导入 JSON／CSV 备份。包内 MCP 与主程序需要一起更新。

启动默认只显示原生栏；点击「今天」打开主界面，`Ctrl+Alt+Space` 打开快速输入。主界面关闭后保留 30 秒再释放，托盘退出才结束后台。

## 验证范围

本版业务源码基于 `025685b3ff1feac17980f096496cd130cd5e6ca7`，之后本轮只补充文档与公开证据。最终打包必须以干净的文档归档提交重新构建，产物清单记载该最终提交；正常包不启用 `motion-diagnostics`。

已有检查包括 Rust 桌面串行检查 19 项通过（1 项导出器忽略）、最终水滴轮廓的 6 项真实 React 组件检查，以及 TypeScript／Vite 构建、Rust 格式和桌面严格 Clippy。细节见[动效记录](motion-flow-20261030.md)。

首轮业务、MCP、资源与隔离安装的结果保留在[迁移验证报告](validation.md)，不计作本版重新验收。最终 820ms 轮廓的完整桌面录像、普通工具窗口连续收展及混合 DPI 仍需后续实际体验；此次发布不自动操作或覆盖用户已安装的程序。

本次新包的构建、Setup／ZIP 内容、普通应用身份、来源提交和哈希由 Release 附件 `release-verification.json` 记录。它只表示产物核对，不表示已安装测试或所有功能重新通过验收。
