# 本地清单

面向 Windows 和安卓的个人离线任务应用。界面依据本机滴答清单 Windows 8.2.4.0 还原出的 XAML、主题、字体与日历绘制参数实现；任务、习惯、专注和存储使用独立实现。无需账号、服务器或会员。

项目位置：`D:\dida-local`。原版程序和原版任务数据保持原样；不会自动读取或迁移原版账号资料。启动时为空清单，不混入演示任务。

## 直接使用

- Windows：双击 `启动本地清单.cmd`，或运行 `release\本地清单\本地清单.exe`。便携目录整体保留，不要只拷贝 EXE。
- 安卓：将 `release\本地清单-Android.apk` 传到手机自行安装。最低 Android 8.0，使用系统 WebView；APK 未申请联网权限。
- 原版迁移：从滴答清单导出 CSV，在本应用“设置 → 数据与备份 → 导入数据”选择文件。导入会合并，保留现有内容；不支持的复杂重复规则会给出提示并保留原文。

Windows 数据：`%APPDATA%\DidaLocal\data\database.json`，自动备份在同目录。安卓数据保存在应用私有目录。电脑与手机各自离线存储，跨设备迁移使用 JSON 导出、导入。

请定期导出一份独立备份。卸载安卓应用或清除其应用数据会删除私有数据，卸载前先导出。

## 当前功能

任务支持清单、文件夹、标签、过滤器、优先级、子任务、描述、搜索、置顶、复制、完成历史及垃圾桶恢复。日期支持中文快速输入、跨日任务、每天／工作日／每周／每月／每年重复，月末与闰年使用稳定锚点。

日历提供月／周／日／议程、农历、清单筛选、待安排任务、拖动改期与改时、长按范围创建。另有四象限、番茄专注、每日习惯、浅色／深色主题和手机布局。

Windows 提醒需要程序保持运行，退出、关机或休眠期间不会提醒。安卓任务提醒由系统普通闹钟排程，省电设置可能延迟；通知权限由用户在手机上确认。专注计时跨页面继续，当前进度在退出程序后不保留。

尚未实现原版的全部功能：团队协作、自动云同步、第三方在线日历、附件、桌面小组件及全部复杂重复规则均不在当前版本中。恢复 XAML 并不等于恢复全部原厂业务逻辑；当前还原度以实际交互和截图核对，不承诺百分百一致。

## 开发

```powershell
npm install
npm run build
npm start
```

`npm run dev` 可调试网页界面，网页模式使用浏览器 IndexedDB。网页数据与 Windows／安卓程序数据分别保存。

## 检查与打包

```powershell
npm run typecheck
npm test
npm run test:ui
node scripts/ui-smoke.mjs --electron-only

# 从干净的本地 main 构建
npm run package:win
pwsh -File scripts/build-android.ps1
```

Windows 包含完整文件哈希清单，安卓 APK 验证签名及权限；构建身份见各自 `build-info.json`。版本保持 `0.0.0`，源码 SHA 与产物哈希用于识别本地构建。

安卓构建工具位于 `tools/android`，来源和哈希见 `tool-manifest.json`。签名密钥和随机密码位于 `android-native/private`，已排除 Git，必须长期保留才能升级安装后续 APK；不要公开该目录。

## 验证边界

自动检查使用隔离数据，截图中的任务为测试时创建。浏览器检查覆盖生产组件、桌面与手机布局、主题、拖动、重复任务及导入导出；Windows 另通过隐藏的真实 Electron 窗口验证磁盘保存及冷启动恢复。浏览器手机尺寸检查不能替代安卓真机验收。

安卓 APK 的编译、签名与权限核验记录和 Windows 实际运行报告保存在 `reports`。安卓安装、锁屏提醒、不同手机 WebView 与系统省电行为需在实际手机上验收。
